# nigeria-incidents-data-analysis
This project involves the analysis of data relating to incidents, accidents, and violence recorded in Nigeria. The purpose of the project is to examine the available data, identify important patterns and trends, and present the findings in a simple and understandable way. This project follows a  complete data analysis process, starting from data collection and cleaning, followed by analysis and visualization, and finally presenting the results through an interactive Streamlit dashboard.
# project-objectives
* To clean the dataset
* To analyse incident types
* To analyse incidents by location
* To identify patterns and trends
* to visualize the data
* To develop an interactive dashboard
* To provide recommendations.
# dataset
The dataset used for this project contains information about incidents, accidents, and cases of violence recorded in Nigeria. Before the analysis was carried out, the dataset was inspected and cleaned to improve its quality and make it suitable for analysis. The cleaned dataset was then used for the Python analysis and Streamlit dashboard
# data-cleaning
Data cleaning was an important part of the project because the raw dataset contained information that needed to be prepared before analysis.
The following activities was carried out:
  * Checked the dataset for missing values.
  * Identified and handled duplicate records.
  * Checked the different columns and their data types.
  * Corrected inconsistent information where necessary.
  * Extracted relevant information such as state and incident type.
  * Standardized some of the data to make analysis easier.
  * Prepared the cleaned dataset for visualization and further analysis.
Note: The cleaned dataset was saved seperately and used as the main dataset for the dashboard.
# Data-analysis
Python was used to analyze the cleaned dataset using the research questions I derieved. It also involves the examining the frequency and distribution of different incident categories and locations.
The analysis helped answer the research questions and provided information that could be used to identify important patterns in the dataset. Libraries such as pandas and matplotlib were used to process the data and create visualization.
# data-visualization
Visualizations were created to present the results in a clearer format. Different charts were used to show information such as:
* Distribution of incidents by type.
* Number of incidents recorded by state.
* Frequency of different incident categories.
* Other relevant patterns identified during the analysis.
The use of visualization makes it easier to understand the data without having to examine the raw records individually.
# interactive-dashboard
A Streamlit dashboard was developed to present the results of the analysis in an interactive format. The dashboard provides users with an easier way to explore the incident data and view important through charts, statistics, and ither visual elements.
The dashboard was developed using Python and Streamlit and was tested to ensure that the different components works correctly.
# tools-and-technologies-used
The following tools and technologies were used during the project:
* Python: Used for data cleaning, analysis, and programming.
* Pandas; Used for data manipulation, cleaning, and analysis.
* Matplotlib: Used to create charts and visualizations.
* Jupyter Notebook: Used to perform and document the data analysis process.
* Streamlit: Used to develop the interactive dashboard
* Github: Used to store, organize, and manage the project files.
The analysis provided useful information about the distribution of incidents within the dataset. The analysis demonstrates the importance of properly collected and organized data when making data-driven decisions.

# conclusion
This project demonstrates the use of data analysis techniques to examines incidents, accidents and violence-related data in Nigeria. The project covered important stages of the data analysis process, including data cleaning, exploration, analysis, visualization, and dashboard development.
    The use of Python and Streamlit made it possible to transform the raw dataset into useful information that can be easily explored and understood. The project also demonstrates how data analysis can support better understanding and decion-making.
